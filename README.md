# Global Superstore 2016 Sales Dashboard (Microsoft Excel)

## Project Overview

This project analyzes the **Global Superstore 2016** sales dataset using **Microsoft Excel**. The objective was to clean the data, perform business analysis, and build an interactive dashboard that enables users to explore sales performance across different markets, categories, regions, and customer segments.

The dashboard provides insights into sales trends, profitability, customer information, and top-performing sales representatives using advanced Excel features.

---

## Project Objectives

- Clean and prepare raw sales data for analysis.
- Perform data transformation using Excel functions.
- Analyze sales performance across multiple business dimensions.
- Create an interactive dashboard for business reporting.
- Implement data validation and user-friendly navigation.

- Profit
- Shipping Information
- Postal Code

---

## Data Preparation & Cleaning

The following data cleaning techniques were performed:

- Extracted **Product Sub-Category** using Flash Fill.
- Identified blank Postal Code and Region values using **Go To Special**.
- Replaced missing values with **"N/A"**.
- Created calculated fields for Shipping and Order Aging.
- Used date functions for order analysis.

## Business Analysis Performed

The dashboard helps answer business questions such as:

- Which market generates the highest sales?
- Which product categories perform best?
- Who are the top-performing salespeople?
- What is the sales vs profit comparison?
- How old are pending orders?
- What is a customer's total lifetime spend?
- When was a customer's last purchase?

---

## Data Validation

To improve data integrity:

- Restricted date entry to the year **2016**.
- Created a drop-down list for Market selection.
- Protected calculation sheets from accidental modification.
